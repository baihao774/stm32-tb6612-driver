# STM32F103 TB6612FNG 直流电机驱动示例

基于 STM32F103 标准外设库的 TB6612FNG 直流电机驱动示例代码，使用 A 通道，
支持 PWM 调速、正反转、刹车/滑行停止、待机控制与软启动斜坡。
可作为直流电机驱动类毕业设计 / 课程设计的参考示例。

## 功能特性

- TIM3_CH3 输出 20kHz PWM，超出人耳听觉范围，无调速啸叫
- 占空比 0~100% 连续可调，分辨率 1/3600
- 正转 / 反转方向控制，支持运行中换向
- 三种停止方式：短接刹车（快速停转）、滑行停止、待机（零功耗）
- 升速软启动斜坡：每个控制周期占空比递增 5%，抑制电机启动冲击电流

## 硬件连接

| TB6612FNG 引脚 | STM32F103 引脚 | 说明 |
|---|---|---|
| PWMA | PB0（TIM3_CH3） | PWM 调速输入 |
| AIN1 | PB1 | 方向控制 1 |
| AIN2 | PB5 | 方向控制 2 |
| STBY | PB7 | 待机使能（高电平有效） |
| VCC | 3.3V | 逻辑电源 |
| VM | 电机额定电压 | 动力电源，单独供电 |
| AO1 / AO2 | 电机两端 | A 通道输出 |
| GND | GND | 必须与单片机共地 |

## 使用示例

```c
#include "TB6612.h"

int main(void)
{
    TB6612_Init();                       /* 初始化 PWM 与控制脚 */

    TB6612_SetDir(TB6612_DIR_FORWARD);   /* 正转 */
    TB6612_SetDuty(70);                  /* 目标占空比 70%（软启动爬坡升速） */

    while (1)
    {
        TB6612_Update();                 /* 软启动斜坡推进，每 20ms 调用一次 */

        Delay_ms(20);                    /* 主循环节拍 */
    }
}
```

其他常用操作：

```c
TB6612_SetDuty(0);        /* 滑行停止 */
TB6612_Brake();           /* 短接刹车，快速停转 */
TB6612_Standby(0);        /* 进入待机，输出高阻、零功耗 */
TB6612_Standby(1);        /* 退出待机，恢复原占空比 */
```

## 文件说明

| 文件 | 说明 |
|---|---|
| `TB6612.h` | 引脚配置、参数宏与接口函数声明 |
| `TB6612.c` | 驱动实现：PWM 初始化、方向控制、软启动、刹车/待机 |

## 依赖

- STM32F10x 标准外设库（Standard Peripheral Library）
- 主循环需以固定周期调用 `TB6612_Update()`（建议 20ms）
